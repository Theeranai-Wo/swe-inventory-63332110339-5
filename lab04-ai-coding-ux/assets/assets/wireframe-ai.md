# AI Text Wireframe — ระบบขายและจัดการ Stock RAM

## Persona ที่ใช้ในการออกแบบ

**นัท — พนักงานคลังสินค้า**

* อายุ: 25 ปี
* ตำแหน่ง: พนักงานคลังสินค้า
* ประสบการณ์: ทำงานด้านคลังสินค้า 2 ปี
* อุปกรณ์หลัก: Smartphone และคอมพิวเตอร์ Windows
* ทักษะเทคโนโลยี: 3/5

**เป้าหมายหลัก:** ตรวจสอบจำนวน RAM ในคลังได้อย่างรวดเร็ว บันทึกรับเข้าและขาย RAM ได้ถูกต้อง และลดการกรอกข้อมูลซ้ำหลายรอบ

**Pain points:** ค้นหา RAM จำนวนมากยาก, การกรอกข้อมูลหลายช่องทำให้เกิดข้อผิดพลาดง่าย และข้อมูล Stock อาจไม่เป็นปัจจุบัน

# 1. Login

```text
+------------------------------------------------+
|                  RAM STOCK POS                 |
|                                                |
|                  เข้าสู่ระบบ                   |
|                                                |
|  ชื่อผู้ใช้ *                                  |
|  [________________________________]            |
|                                                |
|  รหัสผ่าน *                                    |
|  [________________________________]            |
|                                                |
|  [ ] จดจำการเข้าสู่ระบบ                       |
|                                                |
|             [ เข้าสู่ระบบ ]                   |
|                                                |
|  ลืมรหัสผ่าน?                                  |
|                                                |
|  [ตัวอย่าง Error]                              |
|  ! รหัสผ่านไม่ถูกต้อง กรุณาตรวจสอบอีกครั้ง     |
|                                                |
+------------------------------------------------+
```

### Usability

* ใช้ฟอร์มสั้น มีเฉพาะข้อมูลที่จำเป็นต่อการเข้าสู่ระบบ
* ปุ่ม **เข้าสู่ระบบ** เป็นปุ่มหลักและอยู่ใต้ฟิลด์ทันที
* มีข้อความ Error เพื่อแจ้งผู้ใช้เมื่อเข้าสู่ระบบไม่สำเร็จ
* ใช้ Label ที่มองเห็นได้ชัดเจน ไม่ใช้ Placeholder แทน Label
* รองรับการใช้งานบนคอมพิวเตอร์ Windows และ Smartphone

### Accessibility

* ทุกฟิลด์มี Label ที่มองเห็นได้
* ช่องที่จำเป็นต้องกรอกมีเครื่องหมาย `*`
* Error มีข้อความอธิบายสาเหตุ ไม่ใช้สีเพียงอย่างเดียว

### Success State

```text
✓ เข้าสู่ระบบสำเร็จ
กำลังนำไปยัง Dashboard...
```

# 2. Dashboard — จัดการ Stock RAM

```text
+----------------------------------------------------------------+
| RAM STOCK POS                              [นัท] [ออกจากระบบ]  |
+----------------------------------------------------------------+
|                                                                |
| Dashboard                                                      |
|                                                                |
| [ ค้นหา RAM หรือ Serial Number: _____________ ] [ค้นหา]        |
|                                                                |
| +----------------+ +----------------+ +----------------------+ |
| | RAM ทั้งหมด    | | RAM พร้อมขาย   | | Stock RAM ต่ำ        | |
| |      128       | |       96       | |         8            | |
| +----------------+ +----------------+ +----------------------+ |
|                                                                |
| RAM ในคลัง                                                      |
|                                                                |
| +------------------------------------------------------------+ |
| | ชื่อ RAM          | Serial Number | ความจุ | Stock | สถานะ | |
| +------------------------------------------------------------+ |
| | Kingston Fury     | KF-00125      | 16GB   | 24    | ปกติ  | |
| | Corsair Vengeance | CV-00126      | 32GB   | 4     | ต่ำ   | |
| | G.Skill Trident   | GZ-00127      | 32GB   | 15    | ปกติ  | |
| +------------------------------------------------------------+ |
|                                                                |
| [ + รับ RAM เข้า ]                 [ ขาย RAM ]                 |
|                                                                |
| อัปเดตล่าสุด: 11/09/2026 13:30                                 |
+----------------------------------------------------------------+
```

### Usability

* มี **Search** อยู่ด้านบนเพื่อค้นหา RAM หรือ Serial Number ได้รวดเร็ว
* แสดงจำนวน RAM ทั้งหมด RAM ที่พร้อมขาย และ RAM ที่มี Stock ต่ำทันที
* แสดงข้อมูลสำคัญ เช่น **ชื่อ RAM, Serial Number, ความจุ, Stock และสถานะ**
* มีปุ่ม **รับ RAM เข้า** และ **ขาย RAM** ให้เข้าถึง Action หลักได้จาก Dashboard โดยตรง
* แสดงเวลาอัปเดตล่าสุดเพื่อให้ผู้ใช้ทราบว่าข้อมูล Stock เป็นข้อมูลล่าสุดหรือไม่

### Accessibility

* ใช้ข้อความระบุสถานะ เช่น **ปกติ, Stock ต่ำ** ร่วมกับการแสดงผล ไม่พึ่งพาสีเพียงอย่างเดียว
* Search มี Label ที่ชัดเจน
* ปุ่มมีข้อความบอกหน้าที่ ไม่ใช้ Icon เพียงอย่างเดียว
* ตารางมีหัวคอลัมน์ชัดเจน

### Validation / Error State

```text
ค้นหา RAM หรือ Serial Number:
[____________________________] [ค้นหา]

ไม่พบ RAM ที่ค้นหา
กรุณาตรวจสอบชื่อ RAM หรือ Serial Number แล้วลองค้นหาอีกครั้ง
```

### Success State

```text
✓ อัปเดต Stock RAM สำเร็จ
ข้อมูล Stock RAM ได้รับการอัปเดตแล้ว
```

# 3. Sell RAM — ขาย RAM

```text
+------------------------------------------------+
| RAM STOCK POS                         [นัท]     |
+------------------------------------------------+
|                                                |
| ขาย RAM                                        |
|                                                |
| Serial Number RAM *                            |
| [________________________________]             |
|                                                |
| [ สแกน Serial Number ]                         |
|                                                |
| ข้อมูล RAM                                     |
| Kingston Fury Beast DDR5 16GB                  |
| Serial: KF-2026-00125                          |
| DDR5 | 16GB | DDR5-6000                        |
|                                                |
| ราคา: ฿1,890                                   |
| Stock คงเหลือ: 24 ชิ้น                         |
| สถานะ: IN STOCK                                |
|                                                |
|                  [ ยกเลิก ] [ ยืนยันการขาย RAM ]|
+------------------------------------------------+
```

### Usability

* ใช้ **Serial Number** เป็นข้อมูลหลักในการระบุ RAM แต่ละชิ้น
* สามารถกรอกหรือสแกน Serial Number เพื่อลดการกรอกข้อมูลด้วยตนเอง
* แสดงรายละเอียด RAM ก่อนยืนยันการขาย เพื่อป้องกันการขายผิดรายการ
* แสดง Stock คงเหลือและสถานะก่อนทำรายการ
* ปุ่ม **ยืนยันการขาย RAM** เป็น Action หลักและแยกจากปุ่มยกเลิกอย่างชัดเจน

### Accessibility

* Label **Serial Number RAM** แสดงให้เห็นอย่างชัดเจน
* ช่อง Serial Number ที่จำเป็นต้องกรอกมีเครื่องหมาย `*`
* ปุ่มมีข้อความระบุหน้าที่ชัดเจน
* ข้อผิดพลาดแสดงเป็นข้อความ ไม่ใช้สีเพียงอย่างเดียว

### Validation / Error State

#### ไม่พบ Serial Number

```text
⚠ ไม่พบ RAM

ไม่พบ Serial Number "KF-XXXX" ในระบบ
กรุณาตรวจสอบ Serial Number แล้วลองอีกครั้ง

[ ปิดหน้าต่าง ]
```

#### ขาย RAM ซ้ำ

```text
⚠ ไม่สามารถขาย RAM ได้

Serial Number นี้ถูกขายไปแล้ว
ไม่สามารถทำรายการขายซ้ำได้

[ ปิดหน้าต่าง ]
```

#### RAM ไม่พร้อมขาย

```text
⚠ RAM ไม่พร้อมขาย

RAM รายการนี้ไม่มีสถานะ IN_STOCK
จึงไม่สามารถทำรายการขายได้

[ กลับไปหน้าขาย RAM ]
```

| [____________________________]                 |

| ความจุ *                                       |
| [ 16GB                     ]                   |
|                                                |

| [ DDR5                     v ]                 |

| [ DDR5-6000               ]                   |
|                                                |

| [____________________________]                 |

### Usability

* เก็บข้อมูลสำคัญของ RAM ได้แก่ ชื่อ, Serial Number, ความจุ, ประเภท และจำนวน
* ใช้ Dropdown สำหรับประเภท RAM เพื่อลดข้อมูลที่ไม่ตรงรูปแบบ
* แสดง Label และเครื่องหมาย `*` สำหรับข้อมูลที่จำเป็น
* Validation แสดงใกล้กับช่องที่ผิดเพื่อให้แก้ไขได้ง่าย
* ปุ่ม **รับ RAM เข้า** เป็น Action หลักของหน้า

### Accessibility

* ทุกฟิลด์มี Visible Label
* ช่องบังคับกรอกมีเครื่องหมาย `*`
* Error อธิบายสาเหตุและแนวทางแก้ไข
* สามารถใช้งานด้วย Keyboard โดยเรียงลำดับจากบนลงล่าง

# สรุปหลักการออกแบบ

Wireframe ทั้งหมดถูกออกแบบโดยยึด Persona **"นัท — พนักงานคลังสินค้า"** และปรับระบบให้เหมาะกับการ **ขาย RAM และจัดการ Stock RAM** โดยเน้น

1. **ค้นหา RAM ได้รวดเร็ว** ด้วยชื่อ RAM และ Serial Number
2. **ตรวจสอบ Stock ได้ทันที** โดยแสดงจำนวน RAM และสถานะสินค้า
3. **ระบุ RAM แต่ละชิ้นด้วย Serial Number** เพื่อป้องกันการขายซ้ำ
4. **ลดการกรอกข้อมูลที่ไม่จำเป็น** ด้วยการสแกน Serial Number และใช้ Dropdown
5. **ลดความผิดพลาดในการขาย** ด้วยการตรวจสอบสถานะ `IN_STOCK` ก่อนขาย
6. **แจ้งเตือนเมื่อ Stock ต่ำ** เพื่อให้สามารถรับ RAM เพิ่มได้ทันเวลา
7. **แสดง Error พร้อมวิธีแก้ไข** ไม่ใช่เพียงแจ้งว่าเกิดข้อผิดพลาด
8. **แสดง Success State หลังทำรายการ** เพื่อยืนยันว่าการขายหรือรับ RAM สำเร็จ
9. **รองรับผู้ใช้ที่มีทักษะเทคโนโลยีระดับ 3/5** ด้วย Label และปุ่มที่ชัดเจน
10. **รองรับ Accessibility** โดยใช้ Visible Label, Required Indicator, ข้อความ Error และข้อความสถานะที่ไม่พึ่งพาสีเพียงอย่างเดียว

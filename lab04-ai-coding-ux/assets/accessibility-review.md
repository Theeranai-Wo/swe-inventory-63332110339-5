# ผลการตรวจสอบ Accessibility Checklist

จากการตรวจสอบ Mockup ระบบจัดการ Stock RAM โดยเปรียบเทียบกับ **AI Text Wireframe, Persona และ UI ที่สร้างขึ้นจริง** พบประเด็นที่ต้องปรับปรุงทั้งด้าน Accessibility และความสอดคล้องของ UI โดยบันทึกข้อผิดพลาดของ AI และการแก้ไขไว้ดังนี้

# ข้อสังเกตเพิ่มเติมจาก AI Text Wireframe

## ความสอดคล้องระหว่าง Persona กับ UI

AI Text Wireframe กำหนด Persona สำหรับการออกแบบไว้อย่างชัดเจนว่า

**นัท — พนักงานคลังสินค้า**

โดยมีเป้าหมายในการตรวจสอบจำนวนสินค้า รวมถึงการรับเข้าและเบิกสินค้าได้อย่างรวดเร็ว

อย่างไรก็ตาม เมื่อตรวจสอบ Mockup UI จริง พบว่าบริเวณข้อมูลผู้ใช้งานใน UI แสดงเป็น **ชื่อบุคคลอื่น** แทนที่จะเป็นชื่อ **"นัท"** ตาม Persona ที่กำหนดไว้ใน AI Text Wireframe

### ปัญหาที่พบ

**[จุดที่ 5 ที่ AI ทำพลาด]**
ข้อมูล Persona ที่ใช้เป็นพื้นฐานในการออกแบบไม่สอดคล้องกับข้อมูลที่แสดงใน UI จริง ทำให้เกิดความไม่ต่อเนื่องระหว่าง Persona, AI Text Wireframe และ Mockup

### การแก้ไข

เปลี่ยนชื่อผู้ใช้งานใน UI ให้สอดคล้องกับ Persona เป็น

**"นัท"**

เพื่อให้ข้อมูลใน Persona, AI Text Wireframe และ Mockup UI เป็นข้อมูลชุดเดียวกัน และสามารถตรวจสอบย้อนกลับได้ว่า UI ถูกออกแบบโดยอ้างอิงจากผู้ใช้งานเป้าหมายที่กำหนดไว้

### ประเภทของปัญหา

* **Consistency:** ข้อมูล Persona และข้อมูลใน UI ไม่ตรงกัน
* **Usability:** ผู้ตรวจสอบอาจเข้าใจว่า UI ถูกออกแบบสำหรับผู้ใช้งานคนละคนกับ Persona
* **Design Traceability:** ข้อมูลจาก Persona ไม่สามารถเชื่อมโยงกับ UI ได้อย่างชัดเจนก่อนการแก้ไข

# สรุปผลการตรวจสอบ

จากการเปรียบเทียบ **Persona → AI Text Wireframe → Mockup UI** พบว่า AI สามารถกำหนดหลักการออกแบบและ Accessibility ไว้ได้หลายส่วน แต่เมื่อสร้าง UI จริงยังพบรายละเอียดบางอย่างที่ไม่สอดคล้องกับข้อกำหนดเดิม

ประเด็นที่พบและแก้ไข ได้แก่

1. **Contrast ของข้อความ** — สีเทาอ่อนมี Contrast ไม่เพียงพอ จึงเปลี่ยนเป็น `#111827`
2. **Visible Label** — Mockup ใช้ Placeholder แทน Label จึงเพิ่ม Label **"ค้นหาสินค้า"**
3. **Required Field** — ช่อง Serial Number RAM ไม่มีเครื่องหมาย `*` จึงเพิ่มสัญลักษณ์หรือ `(จำเป็น)`
4. **Button Label** — ใช้คำว่า **"ตกลง"** ใน Error Modal จึงเปลี่ยนเป็นข้อความที่สื่อการกระทำชัดเจน
5. **Persona กับ UI ไม่ตรงกัน** — AI Text ระบุผู้ใช้งานเป็น **"นัท"** แต่ UI แสดงชื่อบุคคลอื่น จึงแก้ให้เป็น **"นัท"**

โดยการตรวจสอบครั้งนี้ไม่ได้พิจารณาเฉพาะข้อความที่ AI สร้างขึ้น แต่ตรวจสอบต่อไปถึง **UI ที่ AI สร้างจริง** เพื่อค้นหาความแตกต่างระหว่างข้อกำหนดใน Wireframe กับผลลัพธ์ที่ปรากฏใน Mockup

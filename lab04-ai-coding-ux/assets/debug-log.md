## Step 4: Confirmation

ทดลองรันแต่ละฟังก์ชันโดยตรงเพื่อยืนยันสาเหตุ

* `apply_discount(100, 10)` ได้ `99.9` แต่ควรเป็น `90.0` จึงยืนยันได้ว่าสูตรส่วนลดผิด

* `average_price([])` เกิด `ZeroDivisionError` เพราะหารด้วย `len(prices)` ซึ่งมีค่าเป็น 0

* `cheapest_n([50,10,30,20], 2)` ได้ `[20]` จึงยืนยันว่าการ slice เลือกรายการผิด

* `bulk_total([100,100,100], 10)` ได้ `299.9` เพราะ `bulk_total()` เรียก `apply_discount()` ที่มีสูตรผิด

จึงยืนยัน Root Cause ของทั้ง 4 กรณีได้แล้ว

---

## Step 5: Fix and Rerun

ทำการแก้ไขตาม Root Cause ที่ยืนยันแล้ว

### การแก้ไข

1. `apply_discount()`

   * แก้สูตรคำนวณส่วนลดจากการลบ `percent / 100` โดยตรง
   * เป็นการคำนวณ `price * percent / 100` แล้วนำไปหักจากราคา

2. `average_price()`

   * เพิ่มการตรวจสอบกรณี `prices` เป็นรายการว่าง
   * ถ้าว่างให้คืนค่า `0.0` เพื่อป้องกันการหารด้วยศูนย์

3. `cheapest_n()`

   * แก้การ slice จาก `ordered[1:n]` เป็น `ordered[:n]`
   * เพื่อไม่ให้รายการราคาถูกที่สุดถูกข้ามไป

4. `bulk_total()`

   * ไม่ต้องแก้ไขโดยตรง เพราะ logic การรวมราคาถูกต้องอยู่แล้ว
   * เมื่อแก้ `apply_discount()` แล้ว `bulk_total()` จึงทำงานถูกต้องตามไปด้วย

### ทดสอบหลังแก้ไข

รันคำสั่ง:

```text
python -m pytest tests/test_discount.py -v
```

ผลการทดสอบ:

```text

```
